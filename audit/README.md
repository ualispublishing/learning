# Audit and verification evidence

This directory is **not learner material**. It contains source extractions, candidate builds, rejection sets, review queues, semantic evidence, and final attestations used to produce or verify the canonical finished datasets.

## Current high-level status files

- `public_readiness_audit.json` — publication-readiness triage across the canonical learner datasets.
- `live_csv_attestation.json` — row counts, hashes, duplicate checks, rank checks, and cross-deck overlap checks.
- Per-language summaries provide deeper provenance.

Files named `candidate`, `rejections`, `review_queue`, `placeholder`, `archive`, or older version numbers may intentionally contain weak, rejected, obsolete, or placeholder material. They are evidence of the quality process, not study decks.
