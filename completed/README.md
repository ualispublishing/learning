# Completed learning material

This directory is the index for finished, public-ready learning assets.

## Languages

See [`languages/`](languages/) for the canonical Arabic, French, and Urdu datasets and their current publication status.

The CSV files themselves remain at the repository root because the verification/build tooling currently keys those exact paths. They are the canonical versions intended for study, sharing, or reuse.

Completed reference datasets are separate from `subjects/`, which contains only material actually reached in the active learning program. A finished reference deck therefore does not imply personal mastery or course completion.
